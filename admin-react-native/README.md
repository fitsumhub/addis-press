# AddisPress Admin Dashboard (React Native + TypeScript)

Standalone React Native (Expo) Admin Control Center for managing AddisPress bilingual (English / Amharic) editorial content, Android apps, AI tools, ad campaigns, monetization settings, and moderation queues.

## Setup

```bash
cd admin-react-native
npm install
npm run start
```

- Press `a` for Android emulator/device, `i` for iOS simulator, or `w` for web preview.
- Run `npm run typecheck` to verify TypeScript types.
